# MY MOVIE LIST

영화 관람 목록을 관리할 수 있는 클라이언트 사이드 웹 애플리케이션입니다. 영화진흥위원회(KOBIS) API를 연동하여 현재 상영 중인 영화 목록을 자동으로 가져오고, 개인 영화 체크리스트를 관리할 수 있습니다.

## 프로젝트 소개

MY MOVIE LIST는 영화 관람 계획과 기록을 체계적으로 관리하기 위한 개인 맞춤형 영화 목록 관리 도구입니다. 
- 영화진흥위원회(KOBIS) 오픈API를 활용한 실시간 상영 영화 정보 제공
- 4가지 카테고리를 통한 영화 상태 분류
- 드래그 앤 드롭을 통한 직관적인 영화 이동
- 브라우저 Local Storage 기반 데이터 영구 저장
- 반응형 디자인으로 모바일과 데스크톱 환경 모두 지원

## 구현 기능

### 1. 영화 관리 기능

#### 영화 추가/수정/삭제
- **영화 추가**: 하단 플로팅 버튼(+)을 클릭하여 새 영화를 추가
- **영화 수정**: 각 영화 카드의 편집 버튼을 통해 제목, 개봉일, 관람일자 수정
- **영화 삭제**: 삭제 버튼을 통해 영화를 목록에서 제거
- **관람일자**: 관람 예정일을 별도로 기록 가능 (기본값: 미정)

#### 카테고리별 분류
- **시청 고민**: 관람을 고려 중인 영화
- **관람 예정**: 관람을 예정한 영화
- **상영 중·예정**: KOBIS API를 통해 자동으로 가져온 현재 상영/예정 영화 목록
- **시청 완료**: 관람을 완료한 영화

### 2. KOBIS API 통합

#### 자동 영화 목록 로딩
- 최초 접속 시 자동으로 상영 중·예정 영화 목록을 API에서 가져옴
- 현재 날짜 기준 ±2개월 범위의 영화 데이터 수집
- 현재 날짜 기준 ±30일 범위의 영화만 화면에 표시

#### 영화 정보 필터링
- **장르 필터링**: 성인물(에로) 장르 영화 자동 제외
- **제목 키워드 필터링**: 부적절한 키워드를 포함한 영화 제외
- **단일 멜로/로맨스 장르 필터링**: 순수 멜로/로맨스만 있는 영화 제외
- 클린한 영화 목록 제공을 위한 다층 필터링 시스템

#### 상영 중·예정 카테고리 보호
- API에서 가져온 영화는 자동 삭제, 이동, 수정 불가
- 수동으로 영화를 이 카테고리에 추가 가능
- 다른 카테고리로의 이동 시 복사 방식으로 처리 (원본 유지)

### 3. 드래그 앤 드롭

- 영화 카드를 드래그하여 다른 카테고리로 이동
- 카테고리 버튼 위에 드롭하면 해당 상태로 자동 변경
- 드래그 중 시각적 피드백 제공

### 4. 자동 정렬 및 삭제

- **자동 정렬**: 각 카테고리 내 영화 목록을 개봉일 기준 오름차순 자동 정렬
- **자동 삭제**: 
  - '시청 고민', '관람 예정', '시청 완료' 카테고리에서 개봉일로부터 4주(±28일)가 지난 영화 자동 삭제
  - '상영 중·예정' 카테고리는 자동 삭제 제외 (API 데이터 보호)

### 5. 보조 기능

#### 노트 (제작 동기)
- 프로젝트 제작 동기와 개요를 확인할 수 있는 모달
- 읽기 전용 텍스트 형식

#### 시간표
- 주간 영화 관람 시간표 관리 (7일 × 24시간 그리드)
- 각 시간대에 영화 제목 입력 가능
- 요일별로 다른 색상으로 구분
- Local Storage에 자동 저장

#### 상영 시간표 바로가기
- CGV, 메가박스, 롯데시네마, 씨네큐 영화관 사이트 링크 제공
- 호버 시 다른 링크들이 반투명 처리되어 현재 링크 강조

### 6. UI/UX 특징

- **글래스모피즘 효과**: 반투명 카드 디자인으로 세련된 시각적 효과
- **반응형 디자인**: 모바일과 데스크톱 환경 모두 최적화
- **직관적인 아이콘**: Bootstrap Icons를 활용한 일관된 아이콘 시스템
- **시각적 피드백**: 호버, 드래그, 클릭 시 명확한 시각적 반응
- **빈 상태 UI**: 영화가 없을 때 팝콘 이미지와 안내 문구 표시

## 실행 방법

### 로컬 환경에서 실행

1. **프로젝트 클론 또는 다운로드**
   ```bash
   git clone [repository-url]
   cd swClassTest
   ```

2. **웹 브라우저에서 열기**
   - `index.html` 파일을 더블클릭하거나
   - 브라우저에서 `index.html`을 직접 열기
   - 별도의 서버 설정 없이 바로 실행 가능

3. **사용 시작**
   - 최초 접속 시 '상영 중·예정' 카테고리에 자동으로 영화 목록이 로드됩니다
   - 영화 추가, 수정, 삭제 등 모든 기능을 바로 사용할 수 있습니다

### GitHub Pages 배포

1. GitHub 저장소에 프로젝트 업로드
2. Settings → Pages에서 배포 설정
3. HTTPS 환경에서 자동으로 CORS 프록시를 통해 API 호출

## 사용 기술 스택

### Frontend
- **HTML5**: 시맨틱 마크업
- **CSS3**: 
  - Flexbox 레이아웃
  - 글래스모피즘 효과 (`backdrop-filter`, `box-shadow`)
  - 반응형 디자인 (미디어 쿼리)
  - 커스텀 스크롤바 스타일링
- **JavaScript (ES6+)**:
  - DOM 조작
  - 이벤트 리스너
  - 드래그 앤 드롭 API
  - 비동기 처리 (`async/await`)
  - `fetch` API를 통한 HTTP 요청

### 외부 라이브러리 및 서비스
- **Pretendard 폰트**: 웹폰트 (CDN)
- **Bootstrap Icons**: 아이콘 라이브러리 (CDN)
- **KOBIS 오픈API**: 영화진흥위원회 영화 목록 조회 API
  - API 키 필요 (프로젝트에 포함되어 있음)
  - `searchMovieList` 엔드포인트 사용
- **CORS Proxy**: GitHub Pages HTTPS 환경 대응을 위한 프록시 서비스

### 데이터 저장
- **Local Storage**: 브라우저 내장 저장소
  - 영화 목록 데이터
  - 시간표 데이터
  - 카테고리별 상태 관리

## 기타 참고 사항

### API 사용 관련
- **KOBIS API 키**: 프로젝트에 포함된 API 키를 사용하고 있습니다
- **API 호출 제한**: KOBIS API는 일일 호출 제한이 있으니 과도한 새로고침은 피해주세요
- **CORS 프록시**: GitHub Pages 등의 HTTPS 환경에서 HTTP API를 호출하기 위해 CORS 프록시(`corsproxy.io`)를 사용합니다
- **데이터 범위**: 
  - API 호출 범위: 현재 날짜 기준 ±2개월
  - 화면 표시 범위: 현재 날짜 기준 ±30일

### 브라우저 호환성
- Chrome, Edge (최신 버전)
- Safari (최신 버전)
- Firefox (최신 버전)
- 모바일 브라우저 (iOS Safari, Chrome Mobile)

### 데이터 백업
- 모든 데이터는 브라우저의 Local Storage에 저장됩니다
- 브라우저 데이터를 삭제하면 저장된 영화 목록이 함께 삭제됩니다
- 중요 데이터는 별도로 백업하는 것을 권장합니다

### 주의사항
- '상영 중·예정' 카테고리의 영화는 API에서 자동으로 가져온 데이터로, 수정이나 삭제가 불가능합니다
- 다른 카테고리로 이동할 때는 원본이 유지되고 복사본이 생성됩니다
- 자동 삭제 기능은 '시청 고민', '관람 예정', '시청 완료' 카테고리에만 적용됩니다
