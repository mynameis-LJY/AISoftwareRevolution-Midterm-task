# 나만의 MOVIE TO DO LIST 🎬

PRD 문서에 따라 구현된 영화 체크 리스트 웹 애플리케이션입니다.

## 🚀 시작하기

1. `index.html` 파일을 웹 브라우저에서 열기
2. 별도의 서버 설정 없이 바로 사용 가능합니다

## ✨ 주요 기능

### F-01: 영화 항목 추가
- 하단의 `+` 버튼을 클릭하여 새 영화를 추가할 수 있습니다
- 개봉 일자, 영화 제목, 상태를 입력합니다

### F-02: 탭 기반 목록 조회
- 4개의 탭으로 영화를 분류하여 확인할 수 있습니다:
  - 시청 고민
  - 관람 예정
  - 상영 중·예정
  - 시청 완료

### F-03: 항목 상태 변경 (드래그 앤 드롭)
- 영화 카드를 드래그하여 다른 탭으로 이동할 수 있습니다
- 탭 버튼 위에 드롭하면 해당 상태로 변경됩니다

### F-04: 항목 수정 및 삭제
- 각 영화 카드의 ✏️ 버튼으로 수정
- 🗑️ 버튼으로 삭제

### F-05: 자동 정렬
- 각 탭 내의 영화 목록은 개봉 일자 기준으로 오름차순 정렬됩니다

### F-06: 자동 삭제
- 페이지 로드 시, 개봉 일자로부터 21일이 지난 영화는 자동으로 삭제됩니다

## 💾 데이터 저장

모든 데이터는 브라우저의 로컬 스토리지에 저장되며, 브라우저를 닫아도 데이터가 유지됩니다.

## 🎨 디자인

- 모바일 우선 디자인 (최대 너비 420px)
- 그라디언트 배경과 카드 기반 UI
- 반응형 레이아웃

## 📱 브라우저 호환성

최신 버전의 Chrome, Safari, Firefox, Edge에서 정상 동작합니다.
